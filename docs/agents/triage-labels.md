# Triage 标签

各技能用五个规范 triage 角色说话，本文件把角色映射到本仓库 issue tracker 里实际使用的标签字符串。

| mattpocock/skills 里的标签 | 本仓库的标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 维护者需要先评估这个 issue |
| `needs-info` | `needs-info` | 等报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 已完全写清，可交给 AFK agent |
| `ready-for-human` | `ready-for-human` | 需要人来实现 |
| `wontfix` | `wontfix` | 不打算处理 |

技能提到某个角色时（例如「贴上 AFK-ready 标签」），用上表右列对应的标签字符串。
